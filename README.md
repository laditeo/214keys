# 214 ключей · 康熙部首

Интерактивный справочник по всем **214 радикалам Канси** — с японскими и китайскими чтениями, озвучкой и объяснениями на русском.

**Сайт:** [spatilabs.co/214keys](https://spatilabs.co/214keys/) · [basic](https://spatilabs.co/214keys/basic/) · [pynpinyin](https://spatilabs.co/214keys/pynpinyin/)

---

## Возможности

- **Таблица радикалов** — все 214 ключей, сгруппированных по числу черт
- **Поиск** — по иероглифу, чтению, pinyin и тексту объяснения
- **Карточка ключа** — японское и китайское чтение, варианты написания, число черт, пояснение на русском
- **Озвучка** — кнопки 🔊 у чтений; аудио подгружается по группам черт
- **Клик по большому иероглифу** — тематический звуковой эффект (по emoji радикала) + анимация «салют»; **Пробел** — то же в модалке
- **Мини-карта** — в модальном окне слева: вся таблица целиком, рамка видимой области, drag/swipe для прокрутки, клик по кандзи; кнопка сворачивания снаружи панели
- **Навигация** — ←/→ между ключами, ↑/↓ между группами по чертам; те же переходы — кнопками над и под карточкой
- **Тема** — светлая / тёмная (сохраняется в `localStorage`)
- **Шрифт иероглифов** — классический serif или монолинейный sans

---

## Как пользоваться

1. Откройте сайт и найдите нужный ключ в таблице или через поиск.
2. Кликните по иероглифу — откроется карточка с чтениями и объяснением.
3. Нажмите на динамик рядом с **日本語** или **中文**, чтобы услышать произношение.
4. В модалке:
   - **← / →** — предыдущий / следующий ключ в текущей выборке
   - **↑ / ↓** — предыдущая / следующая группа по числу черт
   - **Esc** — закрыть карточку
   - **Мини-карта слева** — клик по ячейке переключает ключ; drag рамки или свайп по карте прокручивает фон; tap вне рамки — прыжок к месту в таблице
5. Переключатели **Светлая / Тёмная** и **Классика / Монолиния** — над полем поиска.

> Мини-карта по умолчанию открыта в альбомной ориентации и свёрнута в портретной.

## Генерация аудио

Озвучка создаётся через Microsoft Edge TTS (`msedge-tts`):

```bash
npm install
npm run generate:audio
```

Файлы пишутся в `audio/jp/` и `audio/cn/` (по одному MP3 на радикал). Лог генерации — в `.gitignore`.

### Пиньинь (`pynpinyin`)

407 слогов собраны в таблицу как в классическом пиньинь-чарте: строки — финали
(`a`, `ai`, `ian`…), столбцы — инициали (`b`, `p`, `m`… `zh`, `ch`, `sh`…);
пустые клетки — несуществующие сочетания. Каждая клетка — иероглиф-пример.

Озвучка — тем же нейронным голосом Edge/Azure TTS (`zh-CN-XiaoxiaoNeural`),
но каждый слог записан **четыре раза**, по одному файлу на тон: текст для синтеза —
сам слог с тоновой разметкой (`zhuāng`, `zhuáng`, `zhuǎng`, `zhuàng`).

```bash
pip install edge-tts
npm run generate:audio:pinyin          # только недостающие файлы
python scripts/generate-pinyin-audio.py --force   # перегенерировать всё
```

Файлы — `audio/pinyin/cn/001-1.mp3` … `407-4.mp3`, отчёт — `pinyin_audio_report.txt`.

Третий тон прогоняется через `scripts/tone3_emphasis.py` (вызывается генератором
автоматически). Отдельный запуск перезаписывает все `*-3.mp3`; повторный запуск
усиливает эффект, поэтому вручную его лучше не гонять дважды.

В карточке слога все четыре тона стоят столбиком; клик по строке или клавиши
**1–4** включают озвучку соответствующего тона. В таблице слог подписан без тона,
а высота голоса не рандомизируется — тон слышно ровно тот, который выбран.

Третий тон дополнительно обработан (TD-PSOLA, `scripts/tone3_emphasis.py`):
голос явно идёт вниз, задерживается внизу и поднимается вверх, как в живой речи.

Переключатель **«Гласные и согласные»** над таблицей включает раскраску: гласные
в слоге и названия финалей — красным, согласные и названия инициали — синим.

В таблице крупным шрифтом набран сам слог, иероглиф — мелкой подписью под ним.

### Деванагари (`devanagari`)

444 акшары собраны в таблицу по классическому принципу варнмалы, повёрнутую
боком: **строки — согласные**, **столбцы — гласные** (как в школьных чартах
Хинди). Согласные идут в порядке варг: `к-варга` (ка…нг), `ч-варга` (ча…нь),
`т-варга` (та…нн), `т-варга` (та…на), `п-варга` (па…ма), затем антахстха
(я ра ла ва), ушман (ша ща са ха) и на конце `ла кша джна`. Первая строка —
самостоятельные гласные (без согласной).

Каждая подпись двуязычная: над столбцом — гласная (`а` / `aa` / `i`…), её
название по-русски и по-английски с подсказкой произношения (`а · a
(as in about)`) и типом гласной (краткий / длинный / двойной / назальный);
слева у согласной — транслитерация, русское название и **артикуляция**
(взрывной безгласный, взрывной придыхательный, аффрикат, носовой,
фрикативный, полугласный) и английский эквивалент. Полосы варг подписаны
`ка-варга · гортанные · velars (throat)`.

Частотность слогов посчитана по опубликованным таблицам частотности хинди
(Wikipedia «वर्ण आवृत्ति», sttmedia letter frequency): 50 самых употребительных
акшар отмечены точкой, переключатель **«Только частые слоги»** приглушает
остальные.

Знаки гласной в деванагари — combining marks, поэтому сам слог не режется на
буквы: раскраска «гласные/согласные» идёт по латинской транслитерации под слогом
(гласные — красным, согласные — синим), а заголовки столбцов (согласные) —
синим, подписи строк (гласные) — красным.

Озвучка — Edge/Azure TTS `hi-IN-SwaraNeural` (женский) и `hi-IN-MadhurNeural`
(мужской), по одному файлу на слог. Переключатель голоса — под надписью «Голос».

```bash
python scripts/generate-pinyin-audio.py --force --tones 1 \
  --audio-root devanagari --out-dir female --voice hi-IN-SwaraNeural \
  --items devanagariItems.js
```

Файлы — `audio/devanagari/female/001-1.mp3` … `444-1.mp3` (и `male/…`).
Экструзия 3D на этой странице отключена: opentype.js не умеет складывать
деванагари (нет shaping), глифы распадаются.

### Звуковые эффекты (клик по иероглифу)

214 коротких `.ogg` подбираются по emoji радикала из [Kenney's Sound Pack](https://kenney.nl/assets) (CC0). Скрипт скачивает их с зеркала gamesounds.xyz:

```bash
npm run generate:sfx
```

Файлы — в `audio/sfx/001.ogg` … `214.ogg`. Если файл недоступен, подставляется запасной UI-звук; в браузере при ошибке загрузки остаётся синтетический «pop».

## Деплой

Боевая версия — **https://spatilabs.co/214keys/** (VPS).

Деплой статики по SSH-ключу (`~/.ssh/id_ed25519`):

```bash
python scripts/deploy.py
```

Скрипт пакует `index.html`, `basic/`, `pynpinyin/`, `css/`, `js/`, `data/` и `audio/pinyin/`,
делает бэкап текущей версии на сервере (`/var/www/spatilabs/214keys.bak-<дата>`)
и распаковывает поверх `/var/www/spatilabs/214keys`.

GitHub Pages (`laditeo.github.io/214keys`) больше не основной канал. Workflow **Deploy GitHub Pages** запускается вручную, если зеркало на Pages всё же нужно.
